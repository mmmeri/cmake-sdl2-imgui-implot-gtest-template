# CMake SDL2 ImGui ImPlot gtest

C++ template for quick and easy bootstrapping of 2D shenanigan projects with some immediate UI and plotting

## Building

```bash
mkdir build
cmake -S . -B build
cmake --build build -j 16
```

## Run
### Windows
```bash
./build/Debug/app.exe
```

### Linux
```bash
./build/app
```
